# 🚀 First Contact — 벽 너머의 정비사

**▶ 바로 하기: https://ejwl27.github.io/first-contact-game/**

소행성 충돌로 우주선이 둘로 갈라졌다. 내 쪽 장치를 고칠 부품은 벽 너머 외계인 정비사의 상자 안에 있다.
벽 구멍으로는 한 번에 물건 하나만 오가고, 소리는 들리지만 서로의 말을 모른다 — "네", "아니요"조차.
옆 칸에서 AI도 똑같은 상황에 놓였다. **외계어를 배워 AI보다 먼저 부품을 받아 수리하면 승리.**

- 한 턴에 하나: 👂 듣기 / ❓ 묻기 (내 물건 + 단어 하나, 대답도 외계어) / 🔧 요청
- 스테이지 4개 (3·4단계는 가끔 구멍이 어두워져 부품 성질 하나가 안 보임), AI 상대 5단계
- AI는 수업에서 배운 공식만 씀: Naive Bayes, Inference by enumeration, Expectimax + 평가 함수, MEU/VPI
- 경주가 끝나면 AI가 턴마다 무엇을 왜 했는지 확률표·VPI로 볼 수 있음

이 저장소에는 게임 파일(`index.html`, 파일 하나로 동작)만 있습니다. 고려대 COSE361 인공지능 프로젝트.
